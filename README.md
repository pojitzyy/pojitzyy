### 📚 Technical Path (What I'm Mastering)
- **Mobile Engineering:** Cross-platform development for **iOS & Android** using **Flutter** & **Dart**, State Management (**Provider**), Offline Storage (**Hive**), and low-end device optimization.
- **Frontend Web:** Advanced **React 19**, **Next.js 15** (App Router), and **TypeScript**.
- **Backend & APIs:** **Node.js**, **Express.js**, and building secure **RESTful APIs** with Swagger documentation.
- **Database & Auth:** **MongoDB (Mongoose)**, **Supabase**, and secure **JWT/Next-Auth** systems.
- **Tools & DevOps:** **Tailwind CSS**, **Shadcn UI**, **Tanstack Query**, **Zustand**, and **Vercel** deployment.
- **Project Management:** Implementing **Scrum Framework** (Sprint Planning, Retrospectives) to ensure efficient development cycles.
